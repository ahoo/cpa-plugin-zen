# Offline exact-Host integration gate

This gate exercises **synthetic protocol and failure handling**, not real Zen identity/gates, quotas, geography, or production availability. Never run `scripts/e2e/run.sh` or `scripts/mint_sessions.py` here; those contact real upstreams.

Run `scripts/offline-e2e/run.sh --plugin /absolute/staged/zen-v0.2.5.so` **only after the staged candidate has been explicitly built and approved for this gate**; do not use `--build` to replace the separately staged 0.2.5 candidate. The runner's alternative `--build` mode builds only a temporary c-shared artifact offline using pinned Go 1.26.8; it never uses `build.sh`, `go mod tidy`, or production discovery. The runner requires cached images for the **unmodified** CLIProxyAPI v7.3.13 Host (`sha256:793691b3817afff2679999bfd173f23e63b0cc05517859f78d8adcc5c5345ea1`), Alpine Python 3.12 HTTP client, and glibc Go 1.26.8/Python 3.13 native ABI probe (`sha256:2166f13e96959cfe4bfe3d2bb208f4e91736a488a1fb7f3a194663dfb5840226`). Missing images fail closed; nothing is pulled. Alpine cannot `dlopen` the glibc plugin.

Pass optional `--previous-plugin /absolute/staged/zen-v0.2.4.so` (pinned staged SHA256 `72dbefb794a9dde35ccf502b79a6892ef7488eb9bbd401ef4200040748e90794`) together with `--plugin` to test isolated 0.2.4→0.2.5 hot switching. Both artifacts must be staged outside production discovery; native ABI registration checks the candidate's exact metadata version, and Host load/reload logs check old/new versions and paths. The runner never overwrites a loaded shared library. It starts a fresh synthetic Host with **only 0.2.4**, `zen.store.version: 0.2.4` and a **healthy synthetic session**. The same valid Mimo Chat completion followed by `[DONE]` and a synthetic `{"choices":[],"cost":{"sentinel":"private-test-value"}}` frame must return **actual HTTP 502** with exactly one v1 `; tail_structure=` summary; the next Mimo request must have no diagnostic suffix. It adds 0.2.5 at a previously unused path **while the Host remains running**, then changes only one selector byte **in place** to 0.2.5. The first post-switch Mimo request must still return **actual HTTP 502**, now with exactly one v2 `; tail_structure_v2=` envelope; the next must again be bare HTTP 502. Responses cost-ping HTTP 200 and paid `jev` remain independent. This order matters: the pinned Host prunes an unselected newer file on cold startup. It requires active/retired-version/path logs and unchanged container PID/start time/restart count. This does not establish that rollback to a formerly loaded path is safe.

The runner creates a Docker `--internal` network, synthetic mock and proxy, and a fresh pinned Host for each isolated fixture. It uses generated config/credentials/pool files and `paid.base_url: http://mock:9999`; `free.members[].proxy_url` points **only** at the synthetic allowlisting proxy `http://mock:9998` in proxy fixtures. Mock telemetry counts both direct upstream requests and proxy attempts (including rejected requests), so zero calls really means no mock network I/O even when the plugin uses its own `stdDoer` instead of a Host callback. The native ABI probe runs separately with `--network none` and synthetic callbacks. No production config/auth/plugin directory, Docker socket, or host port is mounted; proxy environment variables are cleared. All test resources are removed on exit, including failures; the real Host is never restarted.

The original **54-case matrix** remains: three client entrypoints (`/v1/chat/completions`, `/v1/responses`, `/v1/messages`) × stream/non-stream × nine model/error fixtures, including text, tools, usage, SSE framing/terminal events, one explicitly configured paid fallback, and upstream errors. Subsequent fresh Hosts test fallback **false**: exhausted/corrupt/empty/missing session pools and no free member yield **actual HTTP 503** with `earliest_local_retry_at`, no upstream/free/paid/proxy calls, while free SystemOne is exempt from needing a session and paid `jev` stays independent. Synthetic OpenCode-only errors with fallback false return **HTTP 403** after exactly one free request and no paid request; explicit fallback true also stops free rotation/cooling but may make **one authorized paid fallback**, verified by paid request count/credentials and rendered output. The pinned Host strips executor-only `X-Zen-Fallback` from HTTP, so the native ABI probe verifies that marker on the actual executor response. Exhausted-pool explicit-true cases similarly make zero free and one paid call. All three entrypoints in stream and non-stream mode are checked; no HTTP 200 error event is accepted in false-mode 503/403 cases. A real 3-second pool cooldown is allowed to expire naturally before retesting the same model; unexpected Host cross-model caching or continuing 503 **fails** the gate, rather than being waived. The native probe checks error-envelope 503/message and zero HTTP callbacks for both free endpoints and output modes; no real upstream requests or credentials are used.

A separate fallback-**false** tail phase retains all **54 Responses-tail checks**: EOF-terminated upstream Responses SSE (no `[DONE]`) has text, a function call and usage finishing with `response.completed`, followed by an accounting `{"type":"ping","cost":…}`. Only that **exact top-level key set**, with a present opaque cost (object or JSON null), is accepted. Three downstream entrypoints × stream/non-stream must return HTTP 200 with the same text/tool/usage, one success terminal, exactly one authenticated free Responses request, and zero paid/proxy calls. Extra `delta` or `response` fields, missing `cost`, a different event type, or further output or errors **after a valid ping** must instead return actual HTTP 502 after exactly one free call. An HTTP 200 error event, a swallowed later event, or a paid fallback is a failure. The networkless glibc native ABI probe repeats both positive fixtures and every strict negative for `executor.execute` and `executor.execute_stream`, checking their completion/stream chunks or exact 502 error envelopes and one synthetic HTTP callback per attempt.

New isolated `geo` and `geo-paid` phases use a synthetic upstream **HTTP 403** containing the exact phrase `this model is not available in your country`, including mixed-case and Chat/Responses endpoints. They check three downstream routes × stream/non-stream: fallback false preserves HTTP 403 and its original message with precisely one free call and no paid/proxy call; fallback true is allowed **one authorized paid fallback** after that one free call and must render paid output. A read-only directory view of **only the generated synthetic pool** detects file changes immediately after each country denial; an ordinary free request directly afterward proves the sole session/member was not cooled. No real geography, upstream, account or production configuration is exercised. The native probe checks the exact HTTP status, message, unmodified synthetic pool, callback counts, paid marker, and immediately healthy follow-up for both native execution methods.

The six isolated Mimo phases each start a **fresh Host/Executor** so the 0.2.5 one-shot diagnostic is tested through every downstream route × output mode. The identical mock and native synthetic Mimo Chat SSE has valid text, tool, usage, finish and `[DONE]`, then **one** `{"choices":[],"cost":{"sentinel":"private-test-value"}}` frame (never captured from real traffic). **Actual HTTP 502 remains mandatory for both 0.2.4 and 0.2.5**; no Chat post-`[DONE]` event is authorized. For this frame the old v1 summary and the v2 nested legacy summary both have precisely 14 keys: `complete=true`, `done_count=1`, `tail_frames=1`, `extra_fields_count=1`, `output_fields_count=1`, `other_type_count=1`, and **all other counters zero**, including `strict_cost_ping_count=0`. In 0.2.5 only the first Mimo request may append the bounded `; tail_structure_v2=` envelope with exactly `schema:2`, that legacy `summary`, `detail_complete:true`, and `frames:[{"kind":"object","fields":[["choices","empty_array"],["cost","opaque"]],"unknown_fields":0}]`. The **whole marker plus compact JSON** must be at most 1024 bytes; neither the synthetic private cost value nor output/tool strings may appear. Subsequent Mimo calls and the same malformed Chat stream on any other alias remain bare 502. The native probe runs in two separate networkless processes to prove both first-output modes independently and that the Mimo alias and upstream-name lookup share the same one-shot entry. No 0.2.6 repair or acceptance claim is made without real-tail evidence and explicit tests.
